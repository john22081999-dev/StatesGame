# U.S. States Game

A geography guessing game built in Python with turtle and pandas: name as many
of the 50 U.S. states as you can, and each correct guess is labelled on the map.

## Features

- Interactive map of the United States
- Type a state name; if correct, it appears at the right location on the map
- Running score out of 50
- Type "Exit" to stop early and save the states you missed to a CSV
  (`states to learn`) for studying

## Built with

- Python 3
- pandas (reads the states/coordinates CSV)
- turtle (map display)

## How to run

1. Install pandas: `pip install pandas`
2. Run the game: `python main.py`
